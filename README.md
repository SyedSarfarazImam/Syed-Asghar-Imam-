## How to Publish on GitHub Pages (No Coding or Terminal Required)

Follow these simple steps from your web browser:

1. **Extract the ZIP File**  
   Unzip `rafia-enterprises-website.zip` on your computer. Inside, you will see `index.html`, `404.html`, `README.md`, and the `css/`, `js/`, `images/`, and `assets/` folders.

2. **Create a New GitHub Repository**  
   - Log in to [GitHub](https://github.com) and click the **+** button in the top-right corner, then click **New repository**.
   - Give it a name (for example: `rafia-enterprises-website`), select **Public**, and click **Create repository**.

3. **Upload the Website Files**  
   - On your new repository page, click **uploading an existing file**.
   - Select **all files and folders** from inside your extracted folder (`index.html`, `404.html`, `README.md`, `css`, `js`, `images`, `assets`) and drag them into the upload area.
   - Make sure `index.html` sits directly at the top/root level of the repository (not inside an extra subfolder).
   - Scroll down and click **Commit changes**.

4. **Enable GitHub Pages**  
   - In your repository, click **Settings** (top tab bar).
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment** -> **Source**, choose **Deploy from a branch**.
   - Under **Branch**, select **`main`** and folder **`/ (root)`**, then click **Save**.

5. **View Your Live Website**  
   - Wait 1–2 minutes and refresh the **Pages** settings screen.
   - Your live website link will appear at the top (for example: `https://your-username.github.io/rafia-enterprises-website/`).
